# План действий

## Ближайшая цель

Довести MVP до состояния, где пользователь может:

1. Открыть `/start`.
2. Увидеть баланс.
3. Пополнить баланс через Telegram Payments.
4. Создать VPN-ключ.
5. Получить рабочую VPN-ссылку.
6. Пользоваться ключом до истечения оплаченного периода.

## Приоритет 1: Telegram Payments

## Приоритет 2: Тарифы и подписки

Для MVP можно сделать просто:

- фиксированная цена;
- фиксированное количество дней;

Позже можно добавить `Plan`.

### Задачи

- Добавить настройки тарифа:
  - `VPN_KEY_PRICE_KOPECKS`.
  - `VPN_KEY_DURATION_DAYS`.
- При создании ключа проверять баланс.
- Если баланса не хватает — показывать кнопку пополнения.

- Записывать `expires_at`.
- Покрыть тестами сценарии:
  - хватает баланса;
  - не хватает баланса;

## Приоритет 4: Реальная интеграция с Xray

Нужно изучить, как AmneziaVPN подняла Xray на сервере.

### Что нужно получить с сервера

- Как называется Xray container.
- Где лежит Xray config.
- Какие inbound tags используются.
- Включен ли Xray gRPC API.
- Можно ли включить gRPC API без поломки Amnezia.
- Как Amnezia применяет изменения: через config rewrite, API, restart.
- Какие volumes подключены к контейнеру.

### Правильный подход

Сначала сделать read-only аудит:

- подключиться к серверу;
- посмотреть containers;
- посмотреть Xray config;
- не изменять config;
- не рестартить контейнер без отдельного подтверждения.

После аудита выбрать стратегию:

1. Xray gRPC API — предпочтительно.
2. Правка отдельного managed inbound/config fragment — допустимо, если Amnezia не перетирает.
3. Полная правка общего config JSON — нежелательно, высокий риск конфликтов.

### Правило безопасности

Любая write-операция должна трогать только пользователей с `email` prefix `bot:`.

## Приоритет 8: Тестирование и окружения

### Локально

- `XRAY_GATEWAY=fake`.
- Dev endpoints включены только при `DEBUG=true`.
- Webhook через tunnel: `ngrok`, `cloudflared tunnel` или аналог.

### Staging

- Отдельный чистый Xray container.
- Отдельная БД.
- Реальная Telegram test bot конфигурация.

### Production

- Сначала read-only аудит Amnezia Xray.
- Потом включить write-операции только для `bot:` users.
- Перед production включить backup БД и config Xray.
